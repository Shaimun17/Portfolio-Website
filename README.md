# Shaimun Islam Redoy — Personal Portfolio

A modern, responsive, and performance-optimized personal portfolio website built with pure vanilla web technologies.

## 🚀 Live Demo
- [Live Portfolio Link](https://portfolio-website-steel-delta.vercel.app/)

## 🛠️ Built With
- **HTML5** — Semantic structure and accessible markup
- **CSS3** — Custom properties (CSS variables), glassmorphism UI, keyframe animations, and mobile-first responsive layout
- **JavaScript (ES6+)** — Dark/Light theme toggle with `localStorage` persistence, mobile navigation, smooth scrolling, and form validation

## 📌 Featured Highlights
- **Dynamic Theming:** Seamless transition between dark and light modes
- **Medical AI & Research Focus:** Showcases academic research in Computer Vision, Medical AI, and Federated Learning
- **Interactive Components:** Custom animated hero avatar, project showcase, and credentials verification
- **Zero Frameworks:** Built 100% dependency-free with pure Vanilla HTML/CSS/JS
